Звіт з лабораторної роботи №5




Відповіді на контрольні запитання:

1. в індексованих масивах пхп автоматично нумерує елементи по порядку від 0, вони підходять для простих списків, а в асоціативних масивах індексами виступають не числа, а осмислені текстові рядки. Це дозволяє зберігати структуровані дані, де ми звертаємося до значення за його іменем
приклад:

індексований:
$fruits = ['Яблуко', 'Банан']; 
echo $fruits[0]; // Яблуко

асоціативний:
$user = ['name' => 'Дмитро', 'age' => 20]; 
echo $user['name']; // Дмитро


2. складається з двох головних компонентів: масиву, який ми перебираємо ($array), та тимчасової змінної ($item), у яку на кожному кроці копіюється поточне значення
це краще за for, тому що foreach не потребує створення лічильника, він ніколи не вийде за межі масиву, і також for не вміє працювати з текстовими індексами асоціативних масивів


3. викине на екран попередження Warning: Undefined array key "deadline", повернеться null


4. для читабельності, коли ми міксуємо PHP та HTML, якщо використовувати фігурні дужки, то закриваюча дужка десь внизу верстки стає непомітною і незрозумілою, конструкції на кшталт endforeach; або endif; чітко показують, що саме тут закінчується цикл або умова

5. count($array) - рахує і повертає загальну кількість елементів, які знаходяться всередині масиву
in_array('value', $array) - шукає конкретне значення в масиві. Повертає true, якщо знайшло, і false, якщо ні
array_keys($array) — бере асоціативний масив і повертає новий масив, який складається з його ключів


масив $tasks як фрагмент PHP-коду:
$tasks = [
  [
    'id' => 1,
    'title' => 'зробити то сьо',
    'priority' => 'High',
    'isCompleted' => false,
    'timeEstimate' => 2
  ],

  [
    'id' => 2,
    'title' => 'покушать',
    'priority' => 'Medium',
    'isCompleted' => true,
    'timeEstimate' => 4
  ],

  [
    'id' => 3,
    'title' => 'поспать',
    'priority' => 'High',
    'isCompleted' => false,
    'timeEstimate' => 8
  ],

  [
    'id' => 4,
    'title' => 'погулять',
    'priority' => 'Low',
    'isCompleted' => true,
    'timeEstimate' => 1
  ]
];


фрагмент коду, де використовується цикл foreach в HTML-розмітці
<ul>

      <?php foreach ($tasks as $task): ?>

        <li class="<?= $task['isCompleted'] ? 'task-done' : 'task-pending' ?>">
          <strong>Завдання:</strong> <?= formatTitle($task['title']) ?> <br>
          <span class="status-badge">
            <?php if ($task['isCompleted']): ?>
              Виконано
            <?php else: ?>
              В процесі виконання
            <?php endif; ?>
          </span><br>
          <strong>Очікуваний час виконання:</strong> <?= $task['timeEstimate'] ?> год.
        </li>
      <?php endforeach; ?>
    </ul>
