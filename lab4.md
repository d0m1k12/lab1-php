Звіт з лабораторної роботи №4




Відповіді на контрольні запитання:

1. DRY означає "не копіпасть код", якщо ми пишемо один і той самий алгоритм наприклад, перевірку довжини рядка і його обрізання у різних частинах файлу - це порушення DRY. Функції дозволяють запакувати цю логіку в один блок і дати їй ім'я

2. аргументи — це вхідні дані (змінні), які ми передаємо всередину функції під час її виклику, щоб вона могла з ними працювати
параметри за замовчуванням потрібні тоді, коли користувач може не передати якийсь аргумент. Замість фатальної помилки, PHP підставить дефолтне значення
приклад:
function formatTitle($text, $maxLength = 20) { ... }

3. вона відпрацює свої внутрішні алгоритми, але назовні нічого не віддасть, змінна $x отримає значення null

4. це контекст, у якому змінна існує, єдиний правильний спосіб прокинути зовнішню змінну всередину функції - це передати її як аргумент через круглі дужки

5. використовується для обрізання рядка і повернення його частини
приймає такі аргументи:
$string - сам текст, який ми ріжемо
$offset - позиція, з якої треба починати відлік
$length - скільки саме символів треба відрізати. Якщо не вказати, поверне все до кінця рядка


блок коду із тілом створених функцій (formatTitle та getCurrentGreeting):

function formatTitle($text, $maxLength = 20) {
    if (mb_strlen($text, 'UTF-8') > $maxLength) {
        return mb_substr($text, 0, $maxLength, 'UTF-8') . '...';
    }
    return $text;
}

function getCurrentGreeting() {
    $hour = (int)date('H'); 
    if ($hour >= 6 && $hour < 12) {
      return "Доброго ранку"; } 
    elseif ($hour >= 12 && $hour < 18) {
      return "Добрий день"; } 
    elseif ($hour >= 18 && $hour <= 23) {
      return "Добрий вечір"; } 
    else {
      return "Доброї ночі"; }
}
