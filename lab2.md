Звіт з лабораторної роботи №2




Відповіді на контрольні запитання:

1. динамічна типізація це коли тип даних пов'язується з значенням, тобто не треба вказувати який тип даних 

2. на початку php коду ставимо <?php та в кінці ?>

3. обидва вирази виводять значення змінної на екран, але <?= $var ?> є скороченим синтаксисом, він набагато зручніший для вбудовування коротких змінних прямо всередину хтмл-тегів

4. цілі числа: $score = 0; | числа з рухомою комою: $distance = 27.12; | рядки: $error = "Пароль не надійний!"; | логічний: $isDima = true;

5. браузер не виконає цей код тому що хтмл формат файли не передаються на обробку інтерпретатору



код php:

<?php
  $appName = "Task Manager";
  $taskTitle = "виконати лабораторну роботу з PHP";
  $taskTimeEstimate = 2;
?>

<!DOCTYPE html>
<html lang="uk">
<head>
  <title><?= $appName ?></title>
</head>
<body>
  <header>
    <h1><?= $appName ?></h1>
  </header>
  
  <main>
    <h2>Список завдань:</h2>
    <ul>
      <li>
        <strong>Завдання:</strong> <?= $taskTitle ?> <br>
        <strong>Очікуваний час виконання:</strong> <?= $taskTimeEstimate ?> год.
      </li>
    </ul>
  </main>
</body>
</html>
