Звіт з лабораторної роботи №9

фрагмент коду авторизації (login.php):
<?php
session_start();

if (isset($_SESSION['is_logged_in']) && $_SESSION['is_logged_in'] === true) {
    header('Location: index.php');
    exit;
}

$error = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (($_POST['username'] ?? '') === 'admin' && ($_POST['password'] ?? '') === '12345') {
        $_SESSION['is_logged_in'] = true;
        $_SESSION['user_name'] = 'Адміністратор';
        $_SESSION['uid'] = 99;

        setcookie('user_time', time(), time() + 60 * 60 * 24 * 30, '/');
        
        header('Location: index.php');
        exit;
    } else {
        $error = "Невірний логін або пароль!";
    }
}
?>


перенаправлення (обмеження доступу з create.php): 
<?php
session_start();
if (!isset($_SESSION['is_logged_in']) || $_SESSION['is_logged_in'] !== true) {
    header('Location: login.php');
    exit;
}


Відповіді на контрольні запитання:

1. сервер обробляє його і «забуває» про клієнта? він не пам'ятає, що цей самий користувач щойно відкривав іншу сторінку чи входив у систему

2. Cookie — це невеликі дані, які зберігаються на стороні клієнта у браузері і надсилаються на сервер із кожним запитом, користувач може їх бачити і змінювати
дані сесії зберігаються на сервері у файлах у тимчасовій папці сервера, а в браузері лежить лише ідентифікатор сесії

3. Це назва cookie у якому браузер зберігає унікальний ідентифікатор сесії, під час кожного запиту браузер відправляє його серверу, а PHP за цим ідентифікатором знаходить відповідний файл сесії

4. Функція відправляє заголовок із cookie, а заголовки HTTP можна надсилати лише до початку виводу тіла відповіді, якщо перед нею вже був будь-який вивід то PHP видасть помилку і сесія не
запуститься

5. Вона надсилає браузеру заголовок перенаправлення, і браузер переходить на вказану сторінку. Після header() PHP не зупиняє виконання скрипта, тому без exit (або die) решта коду продовжить
працювати через що можуть виконатися захищені дії або вилізти дані які користувач не повинен бачити
